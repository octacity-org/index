# Octacity Index

A map of the repositories that make up [Octacity](https://github.com/octacity-org).

Octacity is an open-source engineering community organized around long-term projects and eight main teams. This repository serves as the central directory for finding projects, teams, community resources, and organization infrastructure.

## Repository Types

Not every repository under Octacity is a software project.

### Project repositories

Software, developer tools, experiments, applications, libraries, and other maintained outputs.

Examples include Gora, fcage, Badbox, Octapowers, and Readme Studio.

### Team repositories

Repositories such as `.ARC`, `.LUCID`, and `.AEGIS` describe the focus and structure of Octacity teams.

They are places for team-level direction, discussions, and coordination rather than standalone software projects.

### Community repositories

Repositories such as `.github` and `membership` define how people participate in Octacity.

They contain organization-wide standards, governance, contribution processes, and membership information.

### Organization repositories

Repositories such as `brand`, `octacity-org.github.io`, `octacity-docs`, `infrastructure`, and `index` support Octacity itself.

## Teams

Octacity is represented by eight main teams.

Team repositories document each team's focus, responsibilities, projects, and working structure.

| Team                                        | Focus                                                                                                                                                           |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Arc](https://github.com/octacity-org/.ARC)     | Applied AI and user-centric productization. ARC focuses on turning technical and AI capabilities into complete, usable products.                                |
| [Lucid](https://github.com/octacity-org/.LUCID) | Artificial intelligence, machine learning, data, evaluation, tooling, and the engineering required to make AI systems understandable, reproducible, and usable. |
| [Aegis](https://github.com/octacity-org/.AEGIS) | One of Octacity's eight main teams. Its specific focus area is still being defined.                                                                             |

Additional team repositories will be added here as the remaining Octacity teams are formed.

## Projects

| Project                                                                | Description                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Gora](https://github.com/octacity-org/gora)                               | Cross-platform preview runtime for strict, local `.gora` UI documents, with native application windows, Studio previews, headless sessions, deterministic captures, semantic inspection, and MCP-driven automation.            |
| [codebase-memory-mcp](https://github.com/octacity-org/codebase-memory-mcp) | Octacity's Zova-native fork of codebase-memory-mcp, providing persistent codebase knowledge graphs, structural and semantic search, cross-repository discovery, incremental indexing, and MCP tooling for coding agents.       |
| [Octapowers](https://github.com/octacity-org/octapowers)                   | Independent fork of Superpowers maintained by Octacity, providing a proportional software-development workflow for Codex, Claude Code, Antigravity, OpenCode, and Codebuff with debugging, testing, verification, review, worktrees, and agent-driven execution. |
| [fcage](https://github.com/octacity-org/fcage)                             | Lightweight process sandbox for running untrusted or semi-trusted commands with explicit filesystem, executable, network, and capability restrictions using native sandboxing mechanisms across macOS, Linux, and Windows.     |
| [Badbox](https://github.com/octacity-org/badbox)                           | Deterministic bad-pattern detector that identifies suspicious structural patterns through static analysis and reports them to developers or coding agents without assuming every finding is automatically wrong.               |
| [Readme Studio](https://github.com/octacity-org/readme-studio)             | Web-based environment focused on writing, previewing, organizing, and assembling project README files.                                                                                                                         |
| [repozip](https://github.com/octacity-org/repozip)                         | Small Rust command-line tool for creating a ZIP archive of the committed state of the current Git repository using `git archive`.                                                                                              |
| [OmniShip](https://github.com/octacity-org/omniship)                       | Portable software delivery pipeline for defining how software is checked, built, and shipped in Python, then executing the pipeline directly or compiling it into provider-native CI workflows.                                |
| [scompress](https://github.com/octacity-org/scompress)                     | macOS tool for transparently compressing Codex and Claude Code session transcripts using native APFS compression while keeping the files directly readable by agents, editors, and other tools.                                |
| [Elephant](https://github.com/octacity-org/elephant)                       | Local, agent-agnostic project memory that stores facts, decisions, tasks, file relationships, and Git context so coding agents can continue work across sessions through MCP and a CLI.                                        |
| [Solo](https://github.com/octacity-org/solo)                               | Native GPU-accelerated desktop application framework for Solid and TypeScript that renders directly through Metal, DirectX, or Vulkan without Electron or a browser-based UI runtime.                                          |
| [ASH](https://github.com/octacity-org/ash)                                 | Agentic shell that lets coding agents securely operate remote machines over SSH through CLI and MCP interfaces for command execution, SFTP file access, and persistent shells without requiring a remote daemon.               |
| [PreToolkit](https://github.com/octacity-org/PreToolkit)                   | Composable machine-learning preprocessing toolkit for building reproducible data preparation pipelines with reusable imputation, encoding, scaling, metadata tracking, and data-leakage-safe transformations.                  |
| [Vigil](https://github.com/octacity-org/vigil)                             | Deterministic change detection for Borsa Istanbul financial statements that downloads KAP filings, checks subtotals and cross-statement reconciliation, and flags material changes with every number traced to its source. Not investment advice. |
